# Project Review Summary

## Overview
- Flutter app for an AI attendance system.
- Main app shell is wired with Go Router and a custom theme system.
- Core flows include authentication, dashboard, classes, sessions, students, reports, profile, settings, and about.

## Architecture
- Entry point: lib/main.dart
- App shell: lib/app.dart
- Routing: lib/core/routing/app_router.dart
- Theme: lib/core/theme/
- Shared services: lib/shared/services/
- Feature modules: lib/features/*/presentation/

## Current Strengths
- Responsive shell with mobile/desktop navigation.
- Session lifecycle logic for starting/stopping attendance and syncing with backend.
- Report generation and export flow.
- Strong separation between UI screens and shared services.

- The main blockers are in tests: widget test imports and app symbol mismatch.
- Several deprecated withOpacity usages remain.
